# Holy Bible KJV

An offline King James Bible for iPad, with Apple Pencil writing and highlighting, notes, bookmarks, search and a one-year daily reading plan.

Open it in Safari at https://charljrcwealth-dev.github.io/Bible-app/, tap Share, then Add to Home Screen. Open it once while online so the whole Bible is saved; after that it works offline. Everything you save stays on your device.

Bible text: King James Version (1769), public domain.
